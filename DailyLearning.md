
Java - high-level programming language developed by Sun Microsystem (Now Oracle).

Platform Independent - Write once, Run anywhere. Thanks to JVM (Java Virtual Machine). 

// Your first Java program
public class HelloWorld {                                  HelloWorld is the name of the Class. 
    public static void main(String[] args) {                Objective Oriented therefore, code is always inside a class.
        System.out.println("Hello, World!");                    public static void main(String[] args) { is the entry point of the program.   
    }                                                          Every Java application starts from this method. 
}
